# Agent Observability — Structured JSONL Events

**Status: DEMO**

A lightweight local event logger for agent and workflow demonstrations. It writes structured JSON Lines records with timestamps, severity, workflow/agent identifiers, and recursively redacted details.

## Capabilities

- Emit structured event records to a local JSONL file.
- Read records back in append order.
- Validate event names and severity levels.
- Recursively redact values under recognized sensitive field names, including password, passphrase, secret, token, authorization, credential, cookie, JWT, API key, private key, client secret, access key, and session identifiers.
- Normalize common field-name styles before matching, including camelCase, spaces, dots, hyphens, and case differences.
- Reject unsupported Python objects rather than silently stringifying them.

## Run tests

Requires Python 3.10+ and uses only the standard library.

```bash
python -m unittest discover -s tests -v
```

## Example

```python
from observability import JsonlEventLogger

logger = JsonlEventLogger("runtime/events.jsonl")
logger.emit(
    "TOOL_DENIED",
    level="WARNING",
    workflow_id="wf-001",
    agent="support-agent",
    details={"reason": "ROLE_NOT_ALLOWED", "apiKey": "never-written"},
)
print(logger.read_events())
```

## Boundaries

- Redaction is based on recognized key names, not on the meaning or content of arbitrary values. Secrets embedded in free text, event names, workflow identifiers, agent labels, unrecognized field names, or encoded values may remain visible. Do not pass secrets or confidential records to the logger.
- The matcher covers common field-name variants; it is not a comprehensive data-loss-prevention system and does not replace input minimization or host-side controls.
- Local append-only usage through this API; the underlying file can still be changed by anyone with filesystem access.
- No centralized telemetry, metrics backend, tracing UI, alerting, retention, rotation, encryption, or tamper-proof audit storage.
- Timestamps are generated by the local system clock.
- Hosts must define data minimization, access, retention, and secure storage policies before production use.
