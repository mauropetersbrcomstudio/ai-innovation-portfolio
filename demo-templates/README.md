# Demo Templates

Reusable starting points for tailoring technical demonstrations to prospective SME clients.

## Template library
- AI customer-support assistant
- CRM lead qualification workflow
- Commercial intelligence dashboard
- Marketing operations automation
- Internal knowledge assistant

Each template must include configurable inputs, a synthetic example dataset, a working happy path, failure handling, setup instructions, and a customization checklist.

**Status:** Template catalogue defined; reusable implementations will be added incrementally.
