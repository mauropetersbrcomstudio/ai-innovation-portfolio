# Public Scope and Data Boundary

**Status: DEMO**

This folder contains a local demonstration attributed to THL at the user's request. Attribution of the name does not validate the demonstrated workflow. The client-confirmed operational baseline is not published.

The public version is limited to generic interface behavior and manually entered demonstration records. It does not publish client source documents, client-specific process maps, real shipment data, logos, personal data, commercial records, metrics, or outcomes.

Use synthetic data only. Do not introduce further identifying details or client-specific source material without documented authorization. A confirmed project workflow is not, by itself, authorization for public disclosure.
