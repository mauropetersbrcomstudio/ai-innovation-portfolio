# Public Scope and Data Boundary

**Status: DEMO**

This folder contains an anonymized local demonstration derived from a client-context project. The client identity and client-confirmed operational baseline are not published because explicit public-disclosure authorization was not found in the project record.

The public version is limited to generic interface behavior and manually entered demonstration records. It does not publish client source documents, client-specific process maps, real shipment data, names, logos, personal data, commercial records, metrics, or outcomes.

Use synthetic data only. Do not reintroduce identifying details or client-specific source material without documented authorization. A confirmed project workflow is not, by itself, authorization for public disclosure.
