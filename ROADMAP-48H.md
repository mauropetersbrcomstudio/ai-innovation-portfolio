# 48-Hour GitHub Portfolio Foundation Sprint

**Objective:** make this GitHub repository a clear, credible, easy-to-navigate portfolio foundation within 24–48 hours. The deliverable is the repository and its folders only — no separate portfolio website.

## Scope
- [x] One central public GitHub repository.
- [x] Eight agreed portfolio categories as folders.
- [x] Two executable demonstrations with setup instructions and tests.
- [x] Automated Python test workflow.
- [ ] Consistent project README and delivery template.
- [ ] Complete category indexes and clear project entry criteria.
- [ ] Add at least one demonstrable starter asset to categories that currently contain documentation only.
- [ ] Verify folder names, links, setup instructions, test commands, and status labels.

## Eight repository areas
1. Client Demos
2. Demo Templates
3. AI Agents & Agentic Systems
4. AI Automation & Workflows
5. AI Skills & Tooling
6. AI Product Development
7. Web Applications & SaaS
8. Marketing Intelligence & Business Automation

## Project standard
Every project should contain, where applicable: problem, fictional or authorized business context, scope, architecture, source code, setup/run instructions, synthetic sample data, tests, limitations, and next steps. Label it CONCEPT, DEMO, PROTOTYPE, or IMPLEMENTED based on evidence.

## Delivery sequence
1. Standardize folder and project documentation.
2. Expand thin categories with small, useful, testable starter projects.
3. Improve the two existing demos and add further executable demonstrations.
4. Check every repository link, folder path, test command, and disclosure.

## Integrity and boundaries
- Fictional scenarios are not claims of work delivered to named companies.
- Do not publish confidential data, credentials, or client identifiers without authorization.
- Do not invent testimonials, metrics, business outcomes, or production deployments.
- No separate website, domain, hosting setup, or web deployment is required.
- Client-specific demos are added when the user supplies the segment and business brief; they are not prerequisites for completing the repository foundation.
